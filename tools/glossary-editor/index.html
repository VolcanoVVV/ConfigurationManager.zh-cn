离线 AI 术语表编辑器

用于 SimpleTranslatorCS 的游戏文本参照表，也兼容客户端 F12 术语表。全程本机编辑，不联网、不填写 API 密钥、不执行翻译任务。

1. 选择文件

服务端：user/mods/Volcano-SimpleTranslator/glossary/eft.zh-CN.tsv。首次未运行时，可打开包内 eft.zh-CN.example.tsv，通过“导出草稿”生成正式文件。请在服务器所在电脑操作。

支持文件授权的浏览器可保存到所选文件；其他浏览器采用下载模式，下载完成后请自行备份并替换目标文件。浏览器不会自动定位服务器路径。

2. 调整设置与词条

仅发送当前原文匹配的词条。字符预算包含参考说明和 JSON，实际还受任务输入预算的 10% 限制；字符数不等于 token 数。上限为 0 或关闭参考不会删除词条。

启用原文（≤80字符）译文（≤120字符）操作

删除、停用和保存都是显式操作；删除最后一条后，空表也会保留，不自动恢复预置。
