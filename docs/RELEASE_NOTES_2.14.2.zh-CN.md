# ConfigurationManager.zh-cn 2.14.2

本次更新把自费声明提前到 **进入 API 翻译模块** 时显示，适用于 F12 汉化工作台和独立网页工作台。

## 相比 2.14.1

- 每次进入 API 模块，都需要等待满 **5 秒**并点击「同意并进入」。取消或关闭弹窗会返回原界面，再次进入需要重新确认。旧版「以后不再弹窗」的选择已失效。
- 声明明确 API 使用用户提供的第三方账户与密钥，实际费用以供应商账单为准。已送达的请求即使取消、超时或未获得可用译文，也可能计费。进入模块后，仍需手动开始翻译。
- 网页的模型查询与翻译接口会校验当前模块的同意状态。离线 CFG 可直接预览，点击「启用 API 翻译」时才需要确认。紧急停止仍可在确认弹窗里使用。

## 下载与升级

| 安装包 | 适用范围 |
| --- | --- |
| F12 Mono | SPT 3.11.x、4.0.x、4.1.x / BepInEx 5 |
| F12 IL2CPP | SPT 5.0 BE / BepInEx 6，请核对实际 BE 构建 |
| 独立网页工作台 | Windows / .NET 8 ASP.NET Core Runtime |

先关闭游戏和旧网页服务，再更新你使用的安装包。若需从 F12 启动网页，请把独立网页包完整解压到游戏根目录。升级前备份 `BepInEx/plugins/zh-cn/` 中的译文、术语表和草稿。服务端文本继续使用对应 SPT 版本的 [SimpleTranslatorCS 1.5.0](https://github.com/VolcanoVVV/SimpleTranslatorCS/releases/tag/1.5.0)。
