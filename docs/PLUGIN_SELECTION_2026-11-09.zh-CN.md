# 插件选择交互调整（2026-11-09）

客户端版本保持 2.13.1，Mono 和 IL2CPP 使用相同交互。

## 使用方式

- 人工精翻、网页机翻、更新检查：侧栏显示当前插件和“更换插件”入口。点击打开独立选择窗口，支持英文名、中文名和 GUID 搜索，点击某个插件直接切换。移除左右逐个切换箭头。
- AI 翻译、接口机翻：侧栏显示已选数量和“选择插件”入口。在独立窗口勾选，点击“应用选择”后才修改批量目标；取消或 Escape 丢弃本次勾选草稿。“全选搜索结果”保留其他已选插件，“清空全部选择”清除全部勾选。
- 列表将英文名和中文名分行、汉化状态放右侧；当前编辑插件优先显示并高亮。列表独立滚动，搜索、取消和应用按钮位于列表外。
- 当前编辑插件和批量目标分别保存在 BepInEx 配置的“工作台选择”节。初次打开默认仅选择当前插件；明确清空的批量列表以 `[]` 保存，下次打开仍为空。已卸载插件从有效目标中排除。

## 未保存译文

切换插件、上一项/下一项、相关字段或鼠标抓取其他文本时，若当前人工输入与已载入文本不同，先显示确认窗口。

- 保存后切换：保存原字段的人工译文，再执行切换；不会额外触发“保存后下一项”。
- 放弃修改并切换：丢弃当前输入，执行目标切换。
- 取消：保留输入和原编辑位置；从插件列表进入时回到列表。

保存失败、原文已变化、目标已消失时保留草稿和确认窗口，不继续切换。长原文和译文在确认窗口中滚动显示。关闭 F12 后本次运行内保留当前人工输入，尚未保存的输入不会写入磁盘，也不跨游戏重启恢复。

## 实现维护

`src/Workbench/TranslationPanel.PluginSelection.cs` 管理选择配置、暂存勾选、窗口、导航保护。两个客户端工程均显式包含该文件。选择模式由 `UsesBatchPluginSelection` 决定，网页机翻使用当前插件。窗口打开、关闭和导航操作在下一次 IMGUI Layout 统一执行，避免事件间控件结构变化。模态窗口拦截背景鼠标并禁用 ConfigurationManager 内容。

- IL2CPP 条件编译 API 冒烟检查通过。
- 原侧栏 7 条位置断言及 210 个屏幕边界案例通过；新选择窗口另覆盖 320×480、640×480 和 1920×1080 屏幕范围。
