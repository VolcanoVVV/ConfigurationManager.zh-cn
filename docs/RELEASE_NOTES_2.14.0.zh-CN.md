# ConfigurationManager.zh-cn 2.14.0

本次发布提供中文版 Mono 和 IL2CPP 两个客户端安装包。两包都包含 F12 汉化与同一套本机网页汉化工作台。

## 和上次 GitHub 公开提交相比

比较基线为此前 `master` 上的 [`1c993ff`](https://github.com/VolcanoVVV/ConfigurationManager.zh-cn/commit/1c993ff69d866c65d1aa8121f1c2feae41bd56ce)。上一份公开源码主要读取 `zh-cn/<GUID>.jsonc`，在菜单上显示插件、配置项和枚举译文，并监听词典变化。以下为从这份源码升级可见的变化。

### F12 汉化与菜单兼容

- 新增游戏内汉化工作台。可逐条精翻、鼠标抓取、用 API 或机翻批量处理、选择显示范围、复核原文更新和调整外观。中文、英文、双语可切换。逐字段优先使用精翻，其次 API 和机翻。
- 可在独立窗口搜索并选择编辑目标，批量操作可多选插件。人工草稿在切换前可保存或放弃。可从原文基准查看插件更新造成的差异。
- Mono 客户端按菜单接口探测 BetterBepInEx，版本号变化本身不会阻止接入。可用时左侧显示「汉化工作台」「鼠标抓取」及三个译文层开关，尺寸跟随 BetterBepInEx。关闭新菜单后可从原版 F12 顶部入口使用。
- 4K 环境首次生成配置时，F12 界面缩放默认为 200%，已有设置保留。修正原版 F12 下拉菜单在放大或滚动时的锚点与展开空间计算。工作台按钮使用自己的样式。
- 插件名称从各自 GUID 词典读取，`UI.json` 用于菜单自身。自绘控件能否采集及显示译文取决于实际绘制路径。富文本保留标记并逐项校验。

### 网页、术语表与词典

- F12 通过「打开网页」启动深蓝色本机工作台。网页可用快照校对、批量翻译、预览更新、保存草稿与查看回执。保存草稿后可在 F12 核对并应用。关闭最后一个网页标签后本地服务会退出。
- 新增网页离线 CFG 导入，可预览静态分类、设置项、说明与可识别的枚举候选，并下载对应 API 词典。运行时生成的内容可回游戏采集。
- F12 与网页共用本机 AI 术语表，支持搜索、导入、预览及离线编辑 UTF-8 TSV。翻译时只提供当前原文命中的词条，并应用相应预算。
- 译文统一归入 `BepInEx/plugins/zh-cn/translations/`，使用 `_Manual.jsonc`、`_API.jsonc`、`_MT.jsonc` 和人工校订用的 `_Manual.overrides.jsonc`。兼容旧分层目录和直接放在 `zh-cn` 根目录的旧词典。首次迁移会归类复制，优先使用已存在的新路径文件，旧文件留存。

### API 翻译、任务日志和费用

- 供应商预设和模型选择支持自动发现及手动填写。按字段与语境组织任务，校验原文标识、富文本、占位符等。批次内的有效译文可单独保留，续跑可跳过已有有效汉化。
- F12 和网页增加开始前的自费确认，首次有 5 秒倒计时。F12 的红色「紧急停止 API」位于开始按钮左侧。紧急停止可拦截尚未启动的任务、取消当前等待并阻止后续请求，可显式恢复。
- API 发送前预留输入和输出预算，受任务请求、Token、连续失败与超时限制。网页保留任务检查点，恢复同一任务时核对当前选择与参数。已到达供应商的请求仍可能扣费，费用以供应商账单为准。
- 日志按任务生成中文命名的「翻译总览」TXT、「翻译过程」和「翻译输入」JSONL，按日另有「错误汇总」与「操作记录」。总览显示进度、插件统计与失败原因。给他人发送前请检查待译内容。

### 配套服务端与运行时

- 兼容的 SimpleTranslatorCS 服务端才会显示「服务端游戏文本」。缺失或不兼容时仍可使用本机 F12 功能。Fika 场景在游戏内验证当前服务端的管理员密钥后解锁相关操作，网页投稿经游戏会话确认及服务端审核。
- 配套服务端更新后，正式译文同步由发布通知触发。新版空闲时无 `/simpletranslator/v1/workbench/live` 轮询，保留手动拉取。
- Mono 使用 SPT 3.11 对应的 BepInEx 5.4.22 基线，减少旧版加载器的新版本依赖警告。IL2CPP 版使用对应 BepInEx 6 和随包提供的 CLR Newtonsoft.Json。此 Release 提供客户端，服务端游戏文本使用对应 SPT 版本的 SimpleTranslatorCS 1.14.0。

## 从本地 2.13.1 升级

BetterBepInEx 左侧改为两行，工作台与鼠标抓取一行，精翻、API、机翻开关一行。工作台顶部把「术语表」「打开网页」「快照与草稿」分组，统一 F12 的六个板块名称。此前的服务端定时拉取已换成发布通知。若旧 `WebWorkbench` 进程正在运行，请先关闭，再使用新的 `网页汉化工作台` 目录。

## 下载与验证

| 客户端 | 选择的安装包 |
| --- | --- |
| SPT 3.11.x、4.0.x、4.1.x | 中文版 Mono |
| SPT 5.0 BE | 中文版 IL2CPP |

先安装对应的 ConfigurationManager 本体。关闭游戏并备份个人译文、术语表和配置，将 ZIP 完整解压至游戏根目录并重启。网页需要 .NET 8 ASP.NET Core Runtime。附件中的 SHA256 清单可校验两个 ZIP。

自动化验证覆盖双运行时安装包、浏览器工作台、译文与任务回归，以及模拟服务端联动。实际游戏内的 4K 下拉、不同 BetterBepInEx 版本、自定义控件和 Fika 联机仍需在对应环境确认。
