# AI 术语表：编辑与生效说明

适用于 ConfigurationManager.zh-cn 2.14.0 和配套的 SimpleTranslatorCS 1.14.0。客户端可在 F12 和网页编辑同一份本机词表。

## 先确定编辑哪张表

| 要翻译的内容 | 实际读取的术语表 | 谁可以修改 |
| --- | --- | --- |
| 本机 F12 插件设置 AI 翻译 | 游戏目录 `BepInEx/plugins/zh-cn/glossary/eft.zh-CN.tsv` | 本机用户，通过客户端窗口或文件编辑 |
| 网页工作台发起的 AI 翻译 | 同一游戏目录的本机词表 | 本机用户，通过网页、F12 或文件编辑 |
| 服务端游戏文本 AI 翻译，包括管理员和玩家投稿 | 服务端当前 Mod 目录 `glossary/eft.zh-CN.tsv` | 服务器文件的运营者 |
| 人工页复制到 AI 网站的提示词 | 发起客户端的本地术语表 | 本机用户 |

两张表相互独立，不自动上传、合并或同步。客户端窗口不提供服务端术语表写接口；Fika 玩家不能通过它修改服务器的参考词条、正式译文或管理员配置。

压缩包只带 `eft.zh-CN.example.tsv`。程序首次读取时，如正式文件不存在，会复制示例；正式文件已存在时不覆盖。**请删除词条而不是删除整个正式文件**，清空的文件也能保留空表。更新 example 不会重置已有表。

## 客户端内置编辑窗口

1. 打开 ConfigurationManager，点击 **汉化工作台 → 术语表**。F12 设置汉化的 **API** 页也有入口。工作台即使没有可翻译插件，也能从顶端按钮打开术语窗口。
2. 新窗口内勾选是否启用参照，设置字符及条目上限；搜索原文或译文，分页查看词条。
3. 点击 **新增词条**，填写原文和译文；取消词条复选框表示停用，**删除** 表示从草稿移除。原文不同写法请分别添加别名，例如 `Ground Zero`、`GroundZero`。
4. 可在免费匹配预览中输入待译原文，点击预览查看会附加哪些参考。预览使用草稿和当前 F12 AI 输入预算，不连接 AI，也不计费。
5. 点击 **校验草稿** 或 **保存**。校验未通过不会写文件。保存时备份旧文件为同目录的 `eft.zh-CN.tsv.日期-随机标识.bak`，然后用临时文件替换正式文件。备份可自行归档或删除。
6. **关闭 / Esc** 遇到未保存内容会提供保存、放弃、继续编辑；通过 F12 隐藏整个配置管理器时，草稿留在本次游戏会话，重新打开编辑窗口可继续。退出游戏不会保存草稿，请先点击保存或导出。

**从剪贴板导入草稿 / 导出到剪贴板** 使用 TSV 文本，导入不会立即保存。已有未保存草稿时，先保存，或导出后关闭并放弃再导入。文件无效时，窗口显示读取错误和修复文本框；可粘贴正确 TSV，导入草稿后保存，旧文件仍会备份。文件超过 256 KiB 时先用文本编辑器缩减。

如果其他编辑器在窗口打开后改了文件，保存会提示冲突并保留磁盘内容。先导出草稿，关闭并放弃，再打开窗口或重新读取文件，手工合并后保存。**定位文件** 只打开文件位置。

## 仅使用服务端：离线小工具

服务端不依赖客户端就能读取已有汉化文件，也能在服务器电脑上编辑自己的术语表。无需额外 exe、安装依赖或登录：

1. 解压完整发布包，在服务器电脑用桌面 Chrome、Edge 或 Firefox 打开包首页的 [`tools/glossary-editor/index.html`](../tools/glossary-editor/index.html)。请保留它旁边的 `glossary-editor.js`；工具可以从任意本地目录运行。
2. 点击 **打开 TSV 文件**，选当前 Mod 的 `glossary/eft.zh-CN.tsv`。若尚未生成正式文件，可打开 example，或点击 **载入预置到草稿**。
3. 编辑词条与预算，使用搜索、分页、停用、删除和免费匹配预览；点击校验。
4. 点击 **保存 / 下载正式 TSV**，根据页面上的模式提示完成保存：
   - **已连接文件**：浏览器支持本地文件授权且所选名称是 `eft.zh-CN.tsv` 时，可直接保存。保存前检查文件变化，发起旧内容 `.bak` 下载，再写回所选文件；请确认下载目录中的备份。
   - **下载模式**，或所选文件是 example / 其他名称：下载 `eft.zh-CN.tsv`，不会改原文件。确认下载完成，备份旧正式文件，然后把下载文件复制到当前 Mod 的 `glossary/eft.zh-CN.tsv`。避免浏览器自动命名为 `eft.zh-CN (1).tsv` 后直接放错文件名。
5. 页面未保存时关闭会提示；**导出草稿 TSV** 可随时保存有效草稿副本，不覆盖原文件。浏览器直接写入时若发现外部修改，先导出草稿、重新打开文件并手工合并。

工具仅本地编辑，无网络请求、API 密钥输入、服务器登录或远程修改功能。浏览器打不开脚本、功能受限制或服务器无图形界面时，用下方文本方式编辑同一个文件即可。

**仅装服务端当前不能通过此小工具发起 AI 翻译任务。** 它修改下一次任务所用参考；当前任务入口仍是配套客户端工作台。服务器已有人工 / AI / 机翻 JSONC 可以在仅装服务端时正常加载。若游戏没有配套客户端热同步组件，游戏文本文件改动后按服务器加载流程重启 / 重载，并在客户端重新连接或重启以重新取得语言表。

## 直接编辑 TSV

编码为 UTF-8（允许 BOM），每行两列，中间是一个真实 **Tab 制表符**，不是几个空格或字面 `\t`：

```tsv
#@enabled=true
#@maxcharacters=800
#@maxentries=24
Ground Zero	中心区
GroundZero	中心区
raid	战局
hideout	藏身处
```

- `#@enabled=false` 停用整张表；`true` 恢复。
- `#@maxcharacters`：参考字符上限 0–2000，默认 800，包含提示头和 JSON 格式。
- `#@maxentries`：单批条目上限 0–64，默认 24。任一上限为 0 时不附加术语。
- `#` 开头普通行是注释；编辑器停用行格式为 `#~<Tab>原文<Tab>译文`，旧版也会当作注释忽略。普通 `#原文<Tab>译文` 注释不会自动变成可勾选词条；需要重新添加为词条。
- 原文最多80、译文最多120字符；不能含控制字符，原文不能以 `#` 开头。启用词条的原文不能重复（忽略大小写）。编辑器最多2000条，包括停用行，整文件最多256 KiB。
- 原文匹配忽略大小写；带空格词条同时匹配下划线和短横线：`Ground Zero` 匹配 `GROUND_ZERO`，但紧凑的 `GroundZero` 须单独一行。`raid` 不匹配 `raider`。

## token 与生效时间

只把本批实际原文命中的参考附加一次，未命中不附加。预算最多为任务输入字符预算的10%，默认不超过800字符 / 24条；长原文词条优先，超出预算的条目不发送。**字符数不等于 token 数**，实际消费以供应商 usage 和账单为准。匹配预览、文件编辑和客户端译文同步都不调用 AI。

保存后 **下一次 AI 任务** 读取；正在运行的任务保留启动快照。已有译文不会因为改表而后台付费重翻，无关词条修改也不会使同会话请求缓存失效。要改已经翻错的“零号地点”，建议先人工校对为“中心区”；若确实需要重新付费翻译，再明确选择重翻并处理“跳过已有有效汉化”。人工层仍优先。

这是 AI 的优先用词参考，输出需要校对。机器翻译接口不附加 AI 提示词。F12 新译文通常立即刷新。配套新版服务端发布正式译文后会通知客户端同步。已经打开的页面可能需重新打开，dialogue 按工作台重启提示处理。安装新 DLL 仍须重启相应程序。
